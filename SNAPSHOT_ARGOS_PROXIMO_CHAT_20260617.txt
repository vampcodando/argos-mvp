7. CLOUDFLARE WORKERS AI / FLUX
============================================================

Backend:
  functions/api/provider/cloudflare-image.js

Endpoint:
  /api/provider/cloudflare-image

Cloudflare Pages Binding:
  Type: Workers AI
  Variable name: AI
  Value: Workers AI Catalog

Modelo:
  @cf/black-forest-labs/flux-1-schnell

Uso no painel:
  IA IMAGEM / CLOUDFLARE FREE
  FLUX.1 Schnell
  USAR PARA IMAGEM

Problemas encontrados:
1. Primeiro retorno:
   "Workers AI respondeu sem imagem."
   Causa provável: parser esperava bytes, mas o Workers AI retorna objeto com image/base64 ou outro shape.
   Correção planejada/aplicada: extractImageBase64(result) para ler:
     result.image
     result.images[0]
     result.dataURI/dataUri
     string direta
     Uint8Array/ArrayBuffer

2. Erro:
   5006: Error: Length of '/prompt' must be <= 2048

   Decisão:
   NÃO limitar o Mestre/chat.
   Apenas adaptar o payload final enviado ao FLUX.

   Correção planejada/aplicada:
   - no front, para cloudflare_image, enviar só o pedido atual `value`, não promptWithContext;
   - no backend, aplicar compactFluxPrompt(prompt) com FLUX_PROMPT_LIMIT = 2048;
   - preservar linhas prioritárias:
     prompt, imagem, visual, cena, style/estilo, subject, produto, personagem,
     lighting/iluminacao, camera, composition/composicao, negative/negativo,
     avoid/evitar.

3. Erro de deploy:
   Unterminated regular expression
   functions/api/provider/cloudflare-image.js:106:14
   .replace(/
   Causa: patch gerou regex quebrada no JS.
   Correção final sugerida: reescrever totalmente cloudflare-image.js com uma versão limpa, sem regex quebrada.
